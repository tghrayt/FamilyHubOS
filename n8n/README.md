# FamilyHubOS - n8n

This project now uses one n8n workflow:

```text
FAMILYHUBOS-WORKFLOW
```

The workflow contains the first working path in one place:

```text
Telegram/manual trigger
Security allowlist
Context builder
Command parsing
Research placeholder
Source validation placeholder
Meeting builder
Runtime/test result
```

Older split workflow exports were removed because they made the n8n UI noisy.
